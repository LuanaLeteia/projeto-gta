# 🎮 GTA VI — Landing Page

Landing page inspirada no site promocional de Grand Theft Auto VI, desenvolvida como projeto de estudo e portfólio com foco em HTML, CSS, JavaScript e animações com GSAP.

O projeto reproduz uma experiência visual imersiva, utilizando vídeo em background, animações durante o scroll, efeitos de entrada dos elementos e layout responsivo para diferentes dispositivos.

⚠️ Projeto não oficial. Este é um projeto educacional desenvolvido para fins de estudo e portfólio. GTA, Grand Theft Auto e demais marcas relacionadas pertencem aos seus respectivos proprietários.



🚀 Sobre o projeto:

O objetivo deste projeto foi reproduzir a experiência visual de uma landing page promocional moderna, explorando principalmente:

- Estruturação semântica com HTML
- Layout responsivo com CSS
- Animações e transições
- Manipulação do DOM com JavaScript
- Intersection Observer API
- Animações baseadas em scroll
- Controle de vídeo através do scroll
- GSAP e ScrollTrigger
- Organização de arquivos e assets
- Boas práticas de acessibilidade e links externos

A página foi estruturada em diferentes seções para criar uma experiência semelhante a uma página promocional de um grande lançamento de entretenimento.
